1Квантор общности ∀

∀ читается «для любого», «для всех», «для каждого»

∀x ∈ M : P(x)
«Для любого x из множества M выполняется P(x)».
Истинно, если P(x) верно для каждого элемента.
Ложно, если есть хотя бы один элемент, для которого P(x) неверно (контрпример).
💡 Одного исключения достаточно. «Большинство подходит» и «первый подходит» не делают ∀ истинным. В тесте такие варианты ответа всегда неверные.
🔤 Слова «все», «любой», «каждый» в условии означают ∀. Слова «существует», «найдётся», «есть такой» означают ∃.

Лаборатория кванторов: смотри, как идёт проверка

Множество M = { }
Готовые примеры:
Нажми «Проверить».
🧮 В тренажёре бывают задачи на счёт. Пример: «M = {3, 6, 9, 12}, найди произведение чётных элементов». Чётные здесь 6 и 12, произведение 6·12 = 72. Ещё пример: «M = {2, 4, 7, 10}, какая доля элементов чётная?» Чётных 3 из 4, ответ 0,75.

2Квантор существования ∃

∃ читается «существует такой … что», «найдётся такой … что»

∃x ∈ M : P(x)
«Существует такой x из M, что выполняется P(x)».
Истинно, если нашёлся хотя бы один подходящий элемент (пример).
Ложно, если ни один элемент не подходит.
Для ∀ ищем контрпример. Нашёлся — высказывание ложно.
Для ∃ ищем пример. Нашёлся — высказывание истинно.
📐 Задачи с квадратным уравнением, например ∃x ∈ {1,…,6}: x² − 5x + 6 = 0. Разложи на множители: (x−2)(x−3)=0, корни 2 и 3. Если хотя бы один корень входит в множество, высказывание истинно. Подбор корней: их сумма равна числу при x с обратным знаком, произведение равно свободному члену.
⚠️ Ловушка перевода: «удвоенное число на 5 больше самого числа» записывается как 2x = x + 5 (равенство!), а не 2x > x + 5.

Лаборатория выше тоже умеет проверять ∃: выбери «∃ — существует» и запусти. При ∃ проверка останавливается на первом подходящем элементе.

3Отрицание квантора общности

«Неверно, что все…» = «есть хотя бы один, который не…»

¬∀x P(x) ≡ ∃x ¬P(x)
Делаем два шага: 1) заменяем ∀ на ∃; 2) отрицаем предикат.
Работает и в обратную сторону: ∃x ¬P(x) ≡ ¬∀x P(x).

Отрицание неравенства: кликни по знаку

На числовой прямой P и ¬P всегда делят прямую на две части без пересечений. Поэтому граничная точка попадает ровно в одну из них.

P(x): x
⚠️ Частая ошибка: ¬∀x P(x) ≠ ∀x ¬P(x). Отрицание фразы «все сдали» звучит как «кто-то не сдал», а не «все не сдали».
🗣 На естественном языке: «Все гости оплатили проживание» → «Существует гость, который не оплатил проживание». Начинай отрицание со слов «существует … который не …».
🔁 Обратная задача «запиши ∃x(x + 7 ≤ 100) через ∀ и ¬». Отрицаем предикат и ставим ¬∀: ¬∀x (x + 7 > 100).
🔢 «Найди наибольшее целое x». Пример: ¬∀x∈ℤ (3x − 1 > 5) ≡ ∃x (3x − 1 ≤ 5). Решаем 3x ≤ 6, x ≤ 2. Наибольшее целое x = 2.

4Отрицание квантора существования

«Не существует такого, что…» = «для любого — не…»

¬∃x P(x) ≡ ∀x ¬P(x)
Делаем два шага: 1) заменяем ∃ на ∀; 2) отрицаем предикат.
Пример: ¬∃x (x² < 9) ≡ ∀x (x² ≥ 9).
⚖️ У эквивалентных формул одинаковая истинность. Если сказано, что ∀x∈S (x² − 100 ≠ 0) ложно, то ¬∃x∈S (x² − 100 = 0) тоже ложно, считать ничего не нужно. Если ответ просят числом, ложь = 0, истина = 1.
🔢 «Сколько элементов {3,5,7,9,14} удовлетворяют ¬(x² − 49 ≠ 0)?» Двойное «не» снимается: ¬(x²−49 ≠ 0) ⇔ x² = 49 ⇔ x = ±7. В множестве подходит только 7, ответ 1.
🗣 «Существует целое x, такое что 3x − 15 = 0» → отрицание: «Для любого целого x верно, что 3x − 15 ≠ 0».

5Отрицание формул с несколькими кванторами

Отрицание проходит через кванторы слева направо, как волна

Каждый квантор меняется на противоположный (∀ ↔ ∃), порядок переменных сохраняется, предикат в конце отрицается.
¬ ∀x ∃y ∀z R ≡ ∃x ∀y ∃z ¬R

Машина отрицания: жми «Шаг» и смотри, как ¬ проходит вправо

⚠️ Ошибки, которые проверяет тест:
• заменили кванторы, но забыли ¬ перед предикатом;
• поменяли только первый квантор;
• переставили переменные местами: в ∀y∃x R(x,y) первой остаётся y → ∃y∀x ¬R(x,y).
🔢 С равенством внутри: ¬∀x∃y (x + y = 0) ≡ ∃x∀y (x + y ≠ 0). Знак «=» превращается в «≠».

6Законы логики для предикатов

Законы для высказываний работают и для предикатов, плюс правила для кванторов

Двойное отрицание: ¬¬P(x) ≡ P(x)
Де Морган:
¬(A ∧ B) ≡ ¬A ∨ ¬B
¬(A ∨ B) ≡ ¬A ∧ ¬B
Импликация: P → Q ≡ ¬P ∨ Q
Дистрибутивность: P ∧ (Q ∨ R) ≡ (P∧Q) ∨ (P∧R)
Кванторы и связки:
∀x (P ∧ Q) ≡ ∀x P ∧ ∀x Q ✅
∃x (P ∨ Q) ≡ ∃x P ∨ ∃x Q ✅
∀x (P ∨ Q) ≢ ∀x P ∨ ∀x Q ❌
∃x (P ∧ Q) ≢ ∃x P ∧ ∃x Q ❌
Запомни пары: ∀ дружит с ∧, ∃ дружит с ∨.

Почему ∀ нельзя «раскрыть» через ∨: щёлкай по клеткам

Шесть объектов x. Щёлкни по клетке, чтобы поменять истинность P(x) или Q(x).

Импликация и её отрицание: кликай по P и Q

Импликация ложна только в случае «из истины следует ложь», то есть P = И, Q = Л. Поэтому ¬(P→Q) ≡ P ∧ ¬Q.

Главная цепочка из тренажёра:
¬∀x (P → Q) ⟶ ¬ через квантор ⟶ ∃x ¬(P → Q) ⟶ импликацию в ∨ ⟶ ∃x ¬(¬P ∨ Q) ⟶ де Морган ⟶ ∃x (¬¬P ∧ ¬Q) ⟶ ¬¬ снимаем ⟶ ∃x (P ∧ ¬Q)
Так же ¬∃x (R ∧ ¬S) ≡ ∀x (¬R ∨ S). Если в ответах есть и промежуточный вариант ∀x ¬(R ∧ ¬S), выбирай полностью упрощённый.
🔢 Задачи на подсчёт. Пример: X = {1,…,5}, A(x): x > 2, B(x): x чётно. Сколько x делают ¬(A ∧ B) истинным? A ∧ B верно только для x = 4. Остальных 5 − 1 = 4. Удобный приём: посчитай, где верно выражение под ¬, и вычти из общего числа.

7Применение законов логики к предикатам

Отрицание двойного неравенства, поглощение, дистрибутивность

Поглощение (длинное «съедается»):
A ∨ (A ∧ B) ≡ A
A ∧ (A ∨ B) ≡ A
Исключённое третье: A ∨ ¬A ≡ И (тождественно истинно)
Противоречие: A ∧ ¬A ≡ Л (тождественно ложно)
Дистрибутивность (вынос общего):
(A ∨ B) ∧ (A ∨ C) ≡ A ∨ (B ∧ C)
(A ∧ B) ∨ (A ∧ C) ≡ A ∧ (B ∨ C)
Общую букву выносим, а знак между скобками уходит внутрь.

Законы на диаграммах Эйлера–Венна

Круг A — это все x, для которых A(x) истинно. Закрашено то, где выражение истинно. Если закраска слева и справа совпадает, формулы равносильны.

≡

Отрицание двойного неравенства на числовой прямой

Q(x): x > и x ≤
✍️ Алгоритм для ¬Q(x), где Q(x): «x > 3 и x ≤ 10»:
1) «и» меняем на «или»; 2) каждое неравенство отрицаем: > → ≤, ≤ → >.
Ответ: x ≤ 3 ∨ x > 10. Дробные границы (2.7, 9.3) переписываются так же: x ≤ 2.7 ∨ x > 9.3.

Несколько кванторов

Меняем все кванторы, порядок переменных не трогаем, предикат отрицаем.
¬∀x∃y P ≡ ∃x∀y ¬P

Де Морган

¬(A∧B) ≡ ¬A∨¬B
¬(A∨B) ≡ ¬A∧¬B
«и» ↔ «или», ¬ переходит на каждую часть.

Импликация

P→Q ≡ ¬P∨Q
¬(P→Q) ≡ P∧¬Q
¬∀x(P→Q) ≡ ∃x(P∧¬Q)

Кванторы и связки

✅ ∀(P∧Q) ≡ ∀P∧∀Q
✅ ∃(P∨Q) ≡ ∃P∨∃Q
❌ ∀ с ∨ и ❌ ∃ с ∧ не раскрываются.

Упрощения

Поглощение: A∨(A∧B) ≡ A, A∧(A∨B) ≡ A
Дистрибутивность: (A∨B)∧(A∨C) ≡ A∨(B∧C)
A∨¬A ≡ И, A∧¬A ≡ Л

Числовые ответы

Истина = 1, ложь = 0. Долю записывай десятичной дробью (0,75). Для ¬(…) посчитай, где верно выражение внутри, и вычти из общего числа.
